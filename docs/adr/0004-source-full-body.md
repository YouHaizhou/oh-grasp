# internal 模块的 source 字段承载完整函数体原文

oh-grasp 的 JSON IR 中，internal 模块的 `source` 字段语义从「源码/签名」（有歧义，模型据此只给函数声明行）改为**完整函数体原文**，并新增可选的 `sourceLine` 起始行号。校验脚本用**白空格归一后的子串匹配**验证 source 确来自源文件，防编造；「完整函数体」的完整性由 prompt 契约约束——子串匹配拦不住「只给声明行」，因为声明行本身也是合法子串。

之所以让自包含 HTML 内嵌完整源码（体积约翻倍）而非只放签名：viewer 离线、无源文件可回链，弹窗要展示「真实代码」就必须自带文本；而只给签名在首个大文件（archify.mjs，41 个内部模块）上已被证实价值不足。行号仅做类型校验（须为整数）、不校验其值是否正确，故 `sourceLine` 为可选字段。
