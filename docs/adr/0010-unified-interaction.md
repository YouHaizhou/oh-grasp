# 交互统一：一个弹窗、四个入口、删掉 B 视图、铺满画布

反馈第 5、7、8 条都是「这张图怎么用」：

5. 连线的箭头/端点被阻挡之后，读者想知道的「这条线上流的是什么」**没有地方能看**；
7. 「整体内容部分可以铺满界面，或者说左右侧空白部分留少点」；
8. 「取消 b 的文档式界面，只展示一个界面」。

第 8 条是范围决策：**删掉 B 视图（Index 文档式界面）**。它没有任何 ADR 背书，来源是最初 spec 里的 story 19（「在流程图和索引表之间切换」），既然交互要统一成一个界面，故事 19 随之作废。

## 一个弹窗组件，四个入口

内容**只有一个容器**：一个统一弹窗。它由四个入口唤起，共用标题 + 分节 + 关闭行为：

| 入口 | 唤出什么 |
|---|---|
| 点节点 | 叶子 → 详情（名字 / kind / detail / 依赖行 / 源码）；group → 子图 + 「组间边」+「成员直连外部」两段 |
| 点端口 | 该端口的连接清单（`×N` 点开，最多 12 行，每行 `成员 → 内容 → 对方成员`） |
| 点边 | 四段说明（来源 / 处理 / 输出 / 用途），聚合边则列出其下每条 connection 的四段 |
| 点依赖卡片 | 该 external 的消费者清单（反向索引全列，见 ADR-0011） |

这是把 ADR-0006/0007 时代散在两处的 `openDetail` / `openGroup` 收成一个组件，并补上后两个入口。

## 清单行可点，弹窗维护一层返回

端口弹窗、group 弹窗的「边界数据流」、聚合边弹窗里按来源分组的清单——**每一行都可点**，点开该条 connection 的四段。

弹窗维护**一层返回**（顶部显示 `← 返回 参数解析`）；回到底层后再关才真正关闭。

理由：聚合边的原子 connection **在画布上没有对应的可见边**（顶层被折叠成一条聚合边），四段唯一的到达路径就是清单。若清单不可点（读只列），反馈 2 想要的「点开看它从哪来、经过什么、输出什么、用于什么」在最重要的一类边上就落空了。而如果点进四段就**替换**当前内容，读者会**丢失位置**——关掉之后 group 弹窗也没了，12 行的清单里得重新找回来。一层返回的代价很小：统一弹窗多一个可选的面包屑槽位。

## 点边的命中区 = 整条路径 + 中点标签

`<path>` 描边细，点不中。命中区包含：

- 整条路径的 `stroke-width` 扩大到可点范围（不改变视觉粗细）；
- 中点标签的白色底衬矩形；

两者是同一个 `<a>` 的两个子元素。

## hover = 原生 `title`

hover 只给**当前语言**的轻提示：节点显全名、边显中点短语。用原生 `title` 属性，不自绘浮层。

理由：节点盒里的名字是被 `fitWidth` **截断**过的（`GDX` / 长名），hover 看全名是它的真实用处，不是装饰。原生 `title` 零成本、零样式负担、不遮挡内容，正合 ADR-0010 之前定的「hover 不承担内容」定位。自绘浮层会诱使人往里塞内容，与「弹窗统一承担内容」打架。

## Esc 关闭

补上键盘关闭。原来只有「点 ×」和「点遮罩空白」，键盘用户被困在弹窗里。

## 删除 B 视图

一并删除：

- `renderB`（索引表渲染）；
- 底部固定条的**样式切换器**；
- URL 参数 `?variant=`；
- **左右方向键**（切换 A/B 的键盘入口）；
- `.scratch/oh-grasp/spec.md` 的 story 19（标作废）。

## 铺满画布

三处：

1. **去掉 `.vA` 的 `max-width: 1060px`**——这正是反馈 7 说的左右留白来源。
2. **画布高度 = `min(内容高度, 视口高度)`**：内容矮时贴合内容不留空带，内容高时保持视口高。写死的 580px 去掉。
3. **`fit()` 允许放大到 1~2×**：原为 `min(1, vw/W, vh/H)`，只在缩小方向工作，小图永远不会放大填满。

第 2 条的两个极端都被否掉了：高度 = 视口高度会让内容只有两三层的小组子图上下各半是空白；高度 = 内容高度则让画布的拖拽/缩放失去意义（内容全在页面上，还拖什么）。取 min 两边都照顾。

## 决策汇总（supersede 关系）

| 决策 | 来源 | 取代 |
|---|---|---|
| 一个弹窗组件、四个入口 | round16-Q1、round17-Q5 | ADR-0006/0007 的 `openDetail` / `openGroup` 两套弹窗 |
| 清单行可点 + 一层返回 | round21-Q3 | — |
| 点边命中区 = 路径 + 中点标签 | round17-Q5 | — |
| hover = 原生 `title`、Esc 关闭 | round19-Q7 | — |
| 删 `renderB` / 切换器 / `?variant=` / 方向键 | round16-Q6 | spec story 19 |
| 去 `max-width`、高度取 min、`fit` 允许放大 | round16-Q5、round19-Q3 | ADR-0007 的固定 580px 画布高 |

## 代价与已知限制

- 删 B 视图**不减功能，只减冗余**：索引表能做的（按名字找、按名字排），依赖卡片侧栏 + 端口清单 + 弹窗搜索已经覆盖。若将来发现「按字母序浏览全部模块」这个动作没人接手，那是**新增一个入口**的问题，不是恢复第二个视图。
- 语言切换器（ADR-0008）占据了原来切换器的位置概念，但它在 header 而不是底部固定条——两者不是替换关系，是**位置巧合**。
