⚖️ **Q3** - **铺满与高度自适应是两件事，且互相冲突**（round16 Q5 的推论）
你的反馈是**左右**留白多（`.vA` 的 `max-width: 1060px`），高度从没提过。但 round16 Q5(a) 里我写的「高度随内容自适应」和「允许放大填满」放一起会打架——**画布高度一旦跟着内容走，就没有「视口高度」可 fit 了**。

🎯 **Q8** - **四段说明要不要限长**（round17 Q3 的推论）
「各一句」是 round17 Q3(a) 的说法，但没定量。
- (a) **prompt 给字数指引**（每段约 ≤40 字），validate 只查非空。
- (b) validate 硬校验长度上限，超了报错。
- (c) 不设上限。

💡 推荐 (a)。硬校验会逼模型为了不超限而牺牲限定语——而「这个路径来自 CLI 参数」这类前提正是长度的来源，砍掉它就把「说明」砍成了「标签」。反过来完全不限，(a)（round18 Q7）那个聚合边弹窗里会有 24 句长短不一的段落。把长度当**风格要求**（prompt）而不是**契约**（validate），两边都不得罪。

ans：a.
