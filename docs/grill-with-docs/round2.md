 Q1 — 可视化的输入→输出范围

  「可视化」目前还很宽，得把它定死成这个唯一能力到底吃进什么、吐出什么：
  - (a) 代码/项目 → 结构概览图：给一个目录，产出它的模块/结构/依赖概览；
  - (b) 自然语言描述 → 流程图/时序图：描述一个流程或系统，画成 flow/sequence；

  🧩 Q3 — 脚本的职责（「增强」到底增强在哪）

  你说要「检验模型输出的脚本」+「给模型提供标准优化的代码文件」，请把它们定成具体职责。我理解的候选：
  - 检验脚本：对模型产出的 Mermaid 做语法校验 + 结构约定校验（如每个模块都被覆盖、命名规范），产出「过/不过 + 错在哪」，让模型据此自纠；

  - 其他（比如渲染/后处理脚本）。
