# 视图变换

**要解决的核心问题**：画布的尺寸是有限的（视口高度 580px），而内容是二维无限延展的。用户要能看全、看细、又不迷路。三个操作：缩放、平移、复位。全部实现为对一个容器元素的 CSS `transform: translate(tx,ty) scale(s)`——SVG 内容不动，只动容器，浏览器合成层处理，性能与内容复杂度无关。

---

## 1. 光标锚定滚轮缩放

**问题**：滚轮缩放最朴素的做法是「以画布中心为锚点」，结果是**想放大的东西越缩越跑出视野**——用户得一边滚一边拖，非常难用。

**做法**：以**鼠标位置**为不动点。设鼠标在视口坐标系里位于 `m`，当前平移 `t`、缩放 `s`，新缩放 `s'`。要求缩放后鼠标下的那个内容点仍在鼠标下：

```
m = t + s·p        （缩放前：鼠标位置 = 平移 + 缩放后内容点 p）
m = t' + s'·p      （缩放后：同一内容点 p 仍在鼠标下）
```

消去 `p` 得：

```
t' = m − (m − t) · (s' / s)
```

代码里就是这一行（viewer.js:489-490）。`m` 由视口 `getBoundingClientRect()` 与 `e.clientX/Y` 相减得到——**必须减 rect.left/top**，否则页面有滚动或视口不在原点时锚点会偏。

缩放步长 1.1 倍（`e.deltaY < 0` 放大），钳制在 **[0.4, 3]**：下限保证缩到再小也点得中端口圆点（6px 半径），上限避免放大到只是看见几个像素。

**边界**：`{passive: false}` + `e.preventDefault()` 阻止页面跟着滚——不给的话滚轮既缩放又滚动页面。

**位置**：viewer.js:484。

## 2. 拖拽平移 + 3px 点击阈值

**问题**：节点和端口有 click 事件，画布也有拖拽。**一次拖拽的起手也是一次 mousedown + mouseup**——浏览器会把它当成 click 发出去，导致「拖完画布顺手点开了一个弹窗」。

**做法**：两次判定

1. **移动阈值**：`mousemove` 时累计位移 `|dx| + |dy| > 3` 才置 `moved = true`。3px 是为了容忍手抖和触控板抖动。
2. **消费一次**：click 处理器第一句就是 `if (ctl.moved) { ctl.moved = false; return; }`——拖过就不算点击，并且**立刻复位**标记（否则接下来的一次真点击也会被吞掉）。

**为什么把 mousemove/mouseup 挂在 `document` 而不是画布上**：拖拽中鼠标很容易移出画布，挂在画布上会丢事件、卡在拖拽态。

**为什么用 `active` 单例**：同一时刻只可能有一个画布在被拖。顶层画布和弹窗子图共用这套监听，靠 `active` 指向当前那个。

**位置**：viewer.js:456-469（监听）、494（mousedown）。
**测试**：`oh-grasp/fortest/smoke-viewer.js` 用 `.dispatch('click', {})` 模拟（桩里 `moved` 恒为 false）。

## 3. 双击 fit（含缩放钳制）

**问题**：用户缩放平移跑偏之后需要一键回到「看全」。

**做法**：

```
s = min(1, vw / W, vh / H)      // 内容比视口大就缩小，否则保持 1（不放大）
tx = (vw − W·s) / 2             // 居中
ty = (vh − H·s) / 2
```

`min` 里的三个量：宽度比、高度比、以及常数 1（**不主动放大**）。

**为什么原本不放大**：内容比视口小时，放大到填满会让小图显得粗糙，且会放大字号的观感差异。**这条已由 ADR-0008 改为允许放大**（用户反馈「左右侧空白多」）——待改为 `min(fitMax, vw/W, vh/H)`，`fitMax` 约 1~2。

**视口尺寸的回退值**（`vw || 900`, `vh || 560`）：JSDOM / 桩环境下 `clientWidth` 为 0，没有回退值会算出 `s = 0`（内容缩成一个点），调试时误以为是布局 bug。

**位置**：viewer.js:476。

## 4. 一套控制器两处复用（`attachFlow`）

**问题**：顶层画布和弹窗里的子图需要**同一套**缩放/平移/复位行为。

**做法**：`attachFlow(vp, zt, W, H, badge)` 把状态（`scale/tx/ty/dragging/...`）、三个事件监听、`apply()`（写 transform）、`fit()` 封成一个闭包对象，返回给调用方。调用方只需给出：视口元素、被变换的容器、内容尺寸、可选的缩放百分比徽标。

顶层调用带 badge（右上角显示 `100%`），子图不传（弹窗里空间紧张）。

**返回值里的 `moved` 是给调用方用的**：节点点击处理器需要读 `sCtl.moved` 来判断这次 click 是不是拖拽的尾巴。传 `null` 给 badge 而不是传一个假元素——调用点因此不需要知道「没徽标时要传什么」。

**位置**：viewer.js:470。
