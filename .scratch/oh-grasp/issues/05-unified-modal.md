# 05 — 一个弹窗：四入口 + 清单行可点 + 一层返回

**What to build:** 把现在散着的两套弹窗收成**一个组件**，由四个入口唤起：点节点、点端口、点边、点依赖卡片。内容全部走这一个容器。**清单里的行可以点**——点开该条 connection 的四段说明——而且弹窗维护**一层返回**（顶部显示 `← 返回 参数解析`），回到底层再关才是真正关闭。

**Blocked by:** 02（端口清单）、04（四段内容）

**Status:** ready-for-agent

- [ ] 一个弹窗组件承担全部详情；四个入口：节点（叶子详情 / 子图 + 两段）、端口（连接清单）、边（四段）、依赖卡片（消费者清单）
- [ ] 端口弹窗的清单行**可点**，点开该条 connection 的四段
- [ ] group 弹窗「边界数据流」的每一行**可点**
- [ ] 聚合边弹窗里按来源分组的清单每一行**可点**
- [ ] 弹窗维护**一层返回**（面包屑 `← 返回 <来源标题>`）；返回后回到底层视图，再关才关闭
- [ ] 关闭行为统一：点 ×、点遮罩空白、按 `Esc` 三者等价，且都遵守「有上一层时先返回、无上一层时关闭」
- [ ] 从清单点进四段再返回，**原来的位置不丢**（回到原来那个 group / 端口弹窗，而不是画布）

**参考**：ADR-0010；spec User Stories 29–37、41。
**备注**：本票是两片偏重的之一（要合并两套现有弹窗 + 加两个新入口）。若执行时塞不进一个上下文窗口，按「骨架（合并 + 四入口）」与「清单行可点 + 一层返回」拆成两票，**后者 blocked by 前者**。
