# 04 — 点边看四段：`connection.description` + 可点命中区

**What to build:** 点一条连线，弹出这条线上「**从哪来 / 经过什么处理 / 输出了什么 / 用于什么**」四句话，中英各一套。IR 的每条 connection 上加一个固定四字段的 `description`。画布中点只放一句**中文动宾短语**（如「传入渲染器路径」），延续既有的「≤3 个不同标签全列、超了折 `+N`」聚合约定。同时让边变得好点：命中区覆盖**整条路径 + 中点标签**，并按上键盘 `Esc` 与当前语言的 `hover` 提示。

**Blocked by:** 01（四段是双语字段，取值走 `pick`）

**Status:** ready-for-agent

- [ ] schema 的 connection 加 `description`，形态为 `{zh: {source, process, output, purpose}, en: {…}}`，四个字段名固定
- [ ] 点边弹出四段，按当前语言显示；切语言后内容跟着换
- [ ] 中点显示**中文动宾短语**，不再是原始英文数据名；聚合规则仍是 ≤3 全列、超了 `+N`
- [ ] 点边命中区 = 整条路径（描边加宽到可点，**不改变视觉粗细**）+ 中点标签的白色底衬
- [ ] hover 用原生 `title`，内容是**当前语言**的：节点显全名、边显中点短语
- [ ] `Esc` 能关闭弹窗
- [ ] 聚合边被点开时，列出其下**每条** connection 的四段（按来源模块分组）——顶层没有可见边的那些原子连接，这是它唯一的到达路径

**参考**：ADR-0008、ADR-0010；spec User Stories 11–19、32–33、37–40。
