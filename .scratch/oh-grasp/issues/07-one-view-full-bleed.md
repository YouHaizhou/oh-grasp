# 07 — 一个界面：铺满 + 删文档式视图

**What to build:** 图上只剩**一个界面**。删掉文档式视图（Index）以及与它有关的一切：视图切换器、`?variant=` URL 参数、左右方向键、它的全部样式。同时把画布铺满——去掉卡住宽度的 `max-width`，高度取「内容高与视口高的小者」，并让「适应」能在两个方向工作（小图放大填满，而不是只缩不放）。

**Blocked by:** 05（文档式视图承担的浏览动作要先被统一弹窗接手，否则删掉就是回归窗口）

**Status:** ready-for-agent

- [ ] 去掉画布的 `max-width`，宽度铺满
- [ ] 画布高度 = `min(内容高度, 视口高度)`，不再写死：内容矮时贴合不留空带，内容高时保持视口高
- [ ] 「适应」允许**放大** 1~2×（原来只在缩小方向工作）；`fit` 语义变成两个方向都能填满
- [ ] 删掉文档式视图的渲染函数、底部切换器、`?variant=` 参数、左右方向键、以及它的全部 CSS
- [ ] 带 `?variant=B` 的**旧链接不再切换视图**（不报错、不空白，就是落回唯一视图）
- [ ] 删除后无残留引用（搜索可断言：切换器 / variant / 视图 B 相关标识符在产物里不再出现）
- [ ] `oh-grasp/examples/` 里那份预生成的样例 HTML 若要保留，需与本票的删除保持一致（否则它演示的是一个已经不存在的界面）
- [ ] 缩放仍是光标锚定、范围仍夹在 `[0.4, 3]`（**不要顺手改掉**）

**参考**：ADR-0010；spec User Stories 41–46；被作废的 story 19 保留标记不删。
