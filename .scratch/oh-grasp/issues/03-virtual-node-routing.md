# 03 — 长边不穿盒：虚节点正交折线

**What to build:** 跨层 ≥ 2 的前向连线不再走曲线（曲线中段现在压在中间层的盒体上）。改为**虚节点正交折线**：在每一对相邻层之间插一个无实体的折点，横向位置取该层的空隙，逐层直角穿下。允许边与边交叉，**只保证不穿盒体**。同时把右侧那条通道**收归反馈边专用**，保住「在右侧 = 数据回流」这个语义信号。

**Blocked by:** None — 可立即开始，**可与 01 / 02 并行**（布局读的是 `module.label`，而它**不翻译**，所以本票不受双语影响）

**Status:** ready-for-agent

- [ ] 跨层 ≥ 2（`to.layer − from.layer ≥ 2`）的前向边渲染为正交折线，各段落在层间空隙里
- [ ] **不穿盒可被纯几何断言验证**：折线各段的横向区间不落在中间层任何盒的 x 区间内（在已有纯内核 seam 上测，不靠肉眼看图）
- [ ] 虚节点**参与层内 barycenter 排序**（与其他节点一同占位、被重排），但不渲染出任何形状
- [ ] 右侧 170px 通道**只放反馈边**；长前向边不再借道侧栏
- [ ] **先确认计数口径**：`countPorts` / `aggregateEdges` / `edgeLabel` 数的是「连接」还是「段」——虚节点一进来两者不再相等，逐个确认并写明（这是本票的前置小重构，不单独开票）
- [ ] 边数 / 段数不再混用的地方，注释里写明单位
- [ ] `docs/algorithms/graph.md` 与 `geometry.md` 同步：分层、barycenter、路由三处的描述与复杂度备注更新

**参考**：ADR-0009；spec User Stories 20–22、28。
**备注**：本票是 eight 片里最重的一片之一。若执行时发现「层内序列」需要新的数据结构、且无法从现有纯内核函数的返回值上断言，优先**给函数多返回一个几何量**，而不是新开测试 seam（见 spec 的 Testing Decisions）。
